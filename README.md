# 财醒 - 财商训练 App MVP

这是根据 `app需求文档.docx` 搭建的第一版无依赖单页 App。它不是普通记账本，而是围绕“财务诊断、现金流、预算、应急金、消费决策、社区交流、月度复盘”的财商训练闭环。

## 当前版本包含

- 登录注册：支持本地注册、登录、退出登录和游客演示。
- 新用户财务诊断：生成财务阶段、健康分、核心问题和本月任务。
- 现金流首页：展示本月收入、支出、结余、储蓄率、应急金进度和消费质量。
- 智能记账基础版：记录收入/支出、账户、类目、钱的质量、必要性和备注。
- 支付宝/微信账单导入：支持导入 CSV/TXT 账单或粘贴账单文本，自动生成流水并跳过重复记录。
- 预算管理：按必要生活、应急金、投资、自我提升、娱乐消费做预算进度。
- 应急金目标：根据必要生活费和目标月份计算目标金额、缺口和预计完成时间。
- 消费决策助手：输入想买的东西和金额，分析收入占比、工作天数、预算影响、应急金延后、消费属性和冷静期建议。
- 社区交流：支持发布动态、选择话题、点赞鼓励和回复，用于用户之间分享省钱、还债、应急金和消费决策经验。
- AI 接口预留：用户不需要配置接口；正式上线时由平台侧后端统一接入 AI 财务教练。
- 月度复盘：自动生成收入、储蓄、预算、应急金和下月建议。

## 数据存储

第一版账号和财务数据都保存在浏览器 `localStorage` 中。每个注册账号会拥有独立的数据空间。点击左侧“重置演示数据”可以恢复当前账号的示例数据。

注意：当前登录注册和社区数据都是产品原型用的本地版本，不适合作为正式上线的安全认证和真实社区方案。正式版本需要接入后端数据库、密码加密、登录态校验、内容审核和数据备份。

## 支付宝/微信账单导入说明

第一版采用“用户导出账单文件后导入”的方式：

- 用户在支付宝或微信中导出个人账单。
- 在 App 的“记账”页面选择来源平台。
- 上传 CSV/TXT 文件，或把表头和账单明细粘贴到文本框。
- App 会识别交易时间、金额、收支方向、交易对方、商品说明和备注，并生成流水。

正式上线时不建议让用户提供支付宝/微信账号密码，也不应该在前端抓取账单。更稳妥的路线是：

- 个人账单：继续使用用户主动导出的文件导入。
- 商户交易：接入支付宝/微信支付商户平台的官方交易接口。
- 后端处理：在服务器解析文件、做去重、导入预览、用户确认和异常记录处理。

## AI 接入说明

消费决策助手当前先用本地规则完成判断。正式上线时，AI 不由用户配置，而是由平台后端统一接入。

前端代码里预留了平台接口常量：

```js
const PLATFORM_AI_DECISION_ENDPOINT = "";
```

上线时把它改成你的后端接口，例如：

```js
const PLATFORM_AI_DECISION_ENDPOINT = "/api/decision";
```

前端会向这个接口发送 `POST` JSON，请求体包含：

- `task`: 固定为 `purchase_decision`
- `purchase`: 用户输入的消费信息
- `financialContext`: 当前收入、预算、应急金、储蓄率和财务阶段
- `localAnalysis`: 本地规则生成的判断结果

后端返回以下任意字段即可显示：

```json
{
  "advice": "这笔消费风险偏高，建议先加入 24 小时冷静清单。"
}
```

正式上线时，OpenAI Key 应只放在后端环境变量中，不能写在前端代码里，也不应该暴露给用户填写。
